# Ollama Documentation Maker
## Description
Ollama Documentation Maker is a tool for generating professional documentation for Python projects. It uses the Ollama Large Language Model to generate documentation for each module in the project.

## Clone & Install
To clone and install the project, run the following commands:
```bash
git clone https://github.com/your-username/ollama-documentation-maker.git
cd ollama-documentation-maker
```
If you are using Linux or macOS, run:
```bash
./setup.sh
``` 
Otherwise, on Windows, execute `setup.bat`.


## Environment Configuration (.env)
To configure the environment, create a `.env` file in the root directory with the following variables:
```makefile
OLLAMA_MODEL=llama3.1
OUTPUT_DIR=docs
```
## Running the Project
To run the project, execute the following command:
```bash
python main.py /path/to/project
```
Replace `/path/to/project` with the path to the project you want to document.

## Architecture
The project consists of the following modules:

* `main.py`: The entry point of the project.
* `src/cli.py`: The command-line interface module.
* `src/llm.py`: The Ollama Large Language Model module.
* `src/scanner.py`: The file scanner module.
* `src/utils.py`: The utility functions module.
* `src/writer.py`: The output writer module.
